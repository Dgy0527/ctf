# 3、Linux基础命令

# `ip addr(ip a)` :显示和配置网络接口信息

# `cat /etc/resolv.conf` :查看DNS配置文件

# `netstat -antlp` :查看系统中的网络连接、监听端口以及对应的进程信息
## -a :显示所有连接和监听端口(包括TCP和UDP)
## -n :以数字形式显示地址和端口号,而不是尝试接信息主机名和服务名
## -t :仅显示TCP协议和相关的连接
## -l :仅显示处于监听状态的端口
## -p :显示与每个连接或端口相关联的进程ID和名称

# `ip route` :显示当前路由信息;优先级数值越小,优先级越高

# `ps aux` :查看当前系统中运行的所有进程的详细信息

# `top` :查看实时的CPU的使用情况

# `uname -a` :显示内核版本、主机名和其他相关信息
# `cat /etc/os-release` :显示操作系统的详细信息(如发行版名称、版本号)

# `df -h` :显示文件系统的磁盘空间使用情况;磁盘空间使用率排查

# `mv 1.txt /root/1` :将当前目录下的文件1.txt移动到/root/目录下并重命名为1

# `chmod 777 1.txt` :赋予所有用户(属主、属组、其他)对该文件的读、写、执行权限

# `chown tomcat:tomcat 1.txt` :将文件1.txt的所有者和所属用户组同时修改为tomcat
## 第一个tomcat表示新的文件所有者
## 第二个tomcat表示新的所属用户组

# 4、powershell常用命令

# `Get-NetIPConfiguration` :查看IP配置,替代ipconfig

# `Test-NetConnection baidu.com` :测试连通性,类似ping(但更详细,含端口测试)

# `Test-NetConnection 192.168.231.166 -Port 22` :测试特定端口,检查端口是否开放

# `Get-NetAdapter` :查看网络适配器,显示网卡状态

# `Get-NetRoute` :查看路由表

# `Get-ComputerInfo` :查看操作系统信息(系统版本、硬件信息)

# `Get-PSDrive C` :查看磁盘空间(C盘)

# `Get-Process` :查看所有进程,显示进程ID、CPU、内存

# `Get-Service` :查看服务列表
