# 附件名称是0宽隐写,结合文件内容有很多的0宽字符,不难想到是0宽隐写

# 隐写工具使用的是http://330k.github.io/misc_tools/unicode_steganography.html这个工具，直接解码可以看到flag:ctfshow{OP_is_for_Over_Power}

# 零宽隐写(文本不可见字符隐写):利用肉眼不可见的Unicode字符（零宽字符）在普通文本中隐蔽地写入一段信息
# 因为零宽字符本身没有宽度（不占空间），所以当你把带有隐藏信息的文本直接粘贴到普通的文本编辑器或网页中时，肉眼看起来和正常的文本完全一模一样，毫无破绽
