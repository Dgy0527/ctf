# `git cherry-pick`
## 将其他分支上的特定某几个提交单独取出,复制并应用到当前所在的分支上(Hash值改变)

# `git cherry-pick C2 C4`

```
git cherry-pick <提交1> <提交2> <...>
这是一种非常直接的方式，用来表达你想将一些提交复制到当前所在的位置（HEAD）下面。
```

```
这里有一个仓库, 我们想将 side 分支上的工作复制到 main 分支。这可以通过变基（即 rebase，我们已经学过了）来完成，但我们来看看 cherry-pick 是怎么做的。

git cherry-pick C2 C4

就是这样！我们想要提交 C2 和 C4，所以 Git 就将被它们抓过来放到当前分支下了。 就是这么简单!
```
