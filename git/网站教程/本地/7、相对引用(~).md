# `~` :相对引用

# `git branch -f main HEAD~3`
## -f(force) 

```
“~”操作符
如果你想在提交树中向上移动很多步的话，敲那么多 ^ 貌似也挺烦人的，所以 Git 也引入了操作符 ~。

该操作符后面可以跟一个数字（可选），用于指定向上移动的次数
```



```
我使用相对引用最多的方式就是移动分支。可以直接使用 -f 选项让分支指向另一个提交。例如:

git branch -f main HEAD~3

这条命令会将 main 分支强制指向 HEAD 的第 3 级 parent 提交。

注意：在真实的 Git 环境中，你当前所在的分支上不允许执行 git branch -f
```
